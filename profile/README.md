# Welcome to Project NoéMI 🤖

Project NoéMI serves as the highly focused core hub for down to earth practical AI tranformation for Businesses and for AI fluency for teams. This includes sodid foundations and framing for AI and agentic tooling. It holds the fundamental architectural blueprints, intelligent modules as well as operational libraries and interfaces that power intelligent workflows, updated daily by members of the project, and validated on a regular basis by George Mason University and many project partners.

## 🎯 Core Engineering & Projects

### The Agent Framework: Library & MCP Infrastructure
The foundation for building intelligent systems. 
- **`agents`**: The central library consolidating all AI agent specifications, extensive documentation, and shared tool usages. This acts as the standard framework for how intelligent tasks operate structurally and independently in an accelerating world. The framework is updated daily, to remove the burden of the acceleration from the organizations who adopt the framework.

### Digital Presence & Presentations
How we share our vision with the enterprise ecosystem and the world. 
- **`website`**: The official web front for Project NoéMI.
- **`NoemiRotary202603`**: An open-source Slidev implementation of our Rotary Presentation highlighting use cases, value, and vision for AI inside enterprise infrastructures.
